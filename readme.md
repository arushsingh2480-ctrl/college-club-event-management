# The Commons: College Club Event Management

A responsive website to manage and display college club events.

## Features
**Student side**
- Home page with club intro, upcoming events and a featured event
- Events page with cards (name, date and time, venue, description)
- Search events by name and filter by category
- Registration form (name, email, college/year, phone) with validation

**Admin side**
- Passcode login
- Add, edit and delete events
- View all registered students
- Search and filter registrations by name, email, college or event

## Setup
No installation needed.
1. Download or clone this repo.
2. Open `index.html` in any browser.

## Admin login
Open the Admin tab and use passcode: `admin123`

## Tech
HTML, CSS and vanilla JavaScript. Data is stored in the browser's localStorage, so this is a front-end demo without a backend.
